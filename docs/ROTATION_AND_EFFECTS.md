# 旋转与效果关系

## 结论

| 角度 | gray | binary | blur | sobel | invert |
|------|------|--------|------|-------|--------|
| 0° | ✓ | ✓ | ✓ | ✓ | ✓ |
| 1–359° | ✓ | ✓ | ✗ 自动关 | ✗ 自动关 | ✓ |

## 原因

`proc_box_blur` / `proc_sobel` 需要 **源图扫描顺序上的 3×3 邻域**。  
旋转采用 **逆映射**：屏幕上每个点独立反算 `(sx,sy)`，邻域像素在源图中不再构成连续窗口，滤波结果错误甚至花屏。

点运算（灰度、二值、反色）只依赖当前像素，故与旋转兼容。

## 实现位置

```24:25:rtl/process/proc_pipeline.v
wire by2 = ~effect_en[2] | rotate_active;
wire by3 = ~effect_en[3] | rotate_active;
```

`rotate_active` 在 `angle != 0` 时为 1。角度回到 0 后 blur/sobel 自动恢复，无需重新发串口命令。

## 若强行旋转+窗滤（扩展题）

可选方案（本工程未实现）：

1. 先旋转到临时缓冲，再做 3×3（多一帧缓冲与带宽）  
2. 在旋转后的坐标网格上做邻域采样（需多路 BRAM 口）  
3. 仅在 0°/90°/180°/270° 开窗滤（轴对齐，邻域仍成立）  

答辩时说明取舍即可。
